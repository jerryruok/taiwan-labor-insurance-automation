# Taiwan Labor Insurance Automation

台灣勞保作業自動化工具，協助降低重複性的人工操作，提升作業效率與一致性。

> **目前狀態：Preview / 預覽階段**

## 主要功能

- 加保作業自動化
- 退保作業自動化
- 投保薪資調整
- Windows Client
- 自動更新
- 版本管理
- 更新檔案完整性驗證
- 作業執行紀錄
